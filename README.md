# Core2Dine Hotel Website

## Project Overview

Core2Dine is a hotel website created using HTML. It provides information about hotel rooms, room comparisons, booking, restaurant menus, hotel facilities, a photo gallery, media, and contact details.

The project demonstrates the use of HTML elements, hyperlinks, tables, forms, images, audio, video, and embedded content.

## Features

- **Home Page:** Introduction to the hotel.
- **Rooms:** Displays hotel room information.
- **Room Comparison:** Compares different room options.
- **Booking:** Provides a hotel booking form.
- **Restaurant:** Displays food items, prices, and restaurant timings.
- **Gallery:** Shows hotel photographs.
- **Media:** Includes hotel promotional audio, video, and a location map.
- **Contact Us:** Provides contact information, a message form, and frequently asked questions.

## How to Run the Project

1. Download or clone this repository.
2. Open the `core2dine` folder in Visual Studio Code.
3. Open `index.html` in a web browser.
4. Navigate through the website using the navigation links.

You can also use the Live Server extension in Visual Studio Code to run the website locally.
